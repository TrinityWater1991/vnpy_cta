# 每日检查清单

> 本页定义 CTA 实盘系统每日运维的标准检查项目，按时间维度分为盘前、盘中、盘后三个阶段。

## 盘前检查 (Pre-market)

执行时间：交易开始前 15-30 分钟。

| 序号 | 检查项 | 检查方式 | 通过标准 | 备注 |
|------|--------|----------|----------|------|
| 1 | 系统进程状态 | `systemctl status vnpy-cta` | 所有进程 Running | 参见 [[health-checks]] |
| 2 | CTP 连接状态 | vnpy 界面 / 日志 | 行情 + 交易通道已连接 | 检查 Login 成功日志 |
| 3 | 行情数据确认 | 查看最新 Tick / K 线 | 行情时间与当前时间偏差 < 3s | |
| 4 | 账户资金确认 | 查询账户权益 | 权益 >= 昨日收盘权益 × 0.95 | 异常波动需排查 |
| 5 | 持仓核对 | 系统持仓 vs 柜台持仓 | 品种 + 多空 + 手数完全一致 | 参见 [[position-reconciliation]] |
| 6 | 策略状态 | 检查策略运行列表 | 所有策略 = "Running" 状态 | |
| 7 | 日志检查 | `journalctl -u vnpy-cta -n 50` | 无 ERROR / CRITICAL 级别日志 | |
| 8 | 磁盘空间 | `df -h` | 使用率 < 80% | `/` 和 `/data` 分区 |
| 9 | 网络延迟 | `ping ctp-server` | 延迟 < 10ms | 参见 [[../troubleshooting/connection-issues]] |

## 盘中监控 (During-market)

执行频率：每 30 分钟巡检一次，或由监控告警触发。

| 序号 | 检查项 | 检查方式 | 通过标准 | 异常处理 |
|------|--------|----------|----------|----------|
| 1 | 策略信号执行 | 检查已成交订单 | 订单状态 = "全部成交" | 参照 [[order-management]] |
| 2 | 持仓变化监控 | 对比系统计算持仓 | 持仓变化与成交记录一致 | 立即触发 [[position-reconciliation]] |
| 3 | 账户风控指标 | 检查动态权益 / 保证金 | 风险度 < 85% | 参照 [[../risk-management/controls]] |
| 4 | 连接稳定性 | 检查 CTP 心跳 | 无重连记录 | 参照 [[../troubleshooting/connection-issues]] |
| 5 | 策略盈亏 | 查看当日 P&L | 单策略回撤 < 预设阈值 | 参照 [[../risk-management/drawdown]] |
| 6 | 日志实时流 | `journalctl -u vnpy-cta -f` | 无连续异常报错 | |
| 7 | CPU / 内存 | `top -b -n 1` | CPU < 80%, 内存 < 80% | 参见 [[health-checks]] |

## 盘后检查 (Post-market)

执行时间：收盘后 15 分钟内。

| 序号 | 检查项 | 检查方式 | 通过标准 | 备注 |
|------|--------|----------|----------|------|
| 1 | 未成交订单 | 检查所有订单状态 | 无未成交订单 | 如有则执行撤单 |
| 2 | 日终持仓确认 | 系统持仓 vs 结算单 | 100% 一致 | [[position-reconciliation]] |
| 3 | 成交记录归档 | 导出当日成交明细 | CSV 文件保存至归档目录 | |
| 4 | 策略日结数据 | 记录各策略当日盈亏 | 写入日结数据库 | |
| 5 | 日志归档 | 轮转当日日志 | `logrotate` 执行成功 | |
| 6 | 备份执行 | 检查备份脚本运行状态 | 数据库 + 配置已备份 | [[../data-management/backup]] |
| 7 | 异常事件记录 | 记录当日异常事件 | 写入 [[../incidents/template]] | 如有事故需复盘 |

## 周度检查项目

|------|--------|------|------|

## 参考指标

| 指标 | 正常范围 | 警告阈值 | 关键阈值 |
|------|----------|----------|----------|
| CTP 行情延迟 | < 1s | 1-3s | > 3s |
| 系统 CPU 使用率 | < 50% | 50-80% | > 80% |
| 磁盘使用率 | < 60% | 60-80% | > 80% |
| 策略信号执行延迟 | < 500ms | 500ms-2s | > 2s |
