# 核心监控指标

本文档定义 vnpy CTA 生产环境所需监控的四大类核心指标：系统层、交易层、风险层和策略层。

## 系统层指标

系统层指标反映服务器基础设施的健康状况，是其他所有监控的基础。

| 指标分类 | 指标名称 | 采集方式 | 告警阈值 | 采集频率 |
|---------|---------|---------|---------|---------|
| CPU | CPU 使用率 | `top` / `psutil` | > 80% | 10s |
| CPU | 平均负载 (load average) | `/proc/loadavg` | > 核心数 × 0.7 | 10s |
| 内存 | 内存使用率 | `free` / `/proc/meminfo` | > 85% | 10s |
| 内存 | Swap 使用率 | `free` / `swapon -s` | > 50% | 30s |
| 磁盘 | 根分区使用率 | `df -h /` | > 80% | 60s |
| 磁盘 | 数据分区使用率 | `df -h /data` | > 85% | 60s |
| 磁盘 | inode 使用率 | `df -i` | > 80% | 300s |
| 网络 | 网卡入向带宽 | `/proc/net/dev` | > 总带宽 × 0.7 | 10s |
| 网络 | 网卡出向带宽 | `/proc/net/dev` | > 总带宽 × 0.7 | 10s |
| 网络 | TCP 连接数 | `ss -s` | > 5000 | 30s |
| 网络 | 网络延迟 (ping broker) | `ping` / 自定义探活 | > 10ms | 5s |

## 交易层指标

交易层指标直接反映策略与市场的交互质量，是发现交易异常的**第一道防线**。

### 行情数据延迟

| 指标 | 说明 | 正常范围 | 告警阈值 |
|------|------|---------|---------|
| tick 到达延迟 | tick 从交易所到本机的时间差 | < 50ms | > 200ms |
| k线更新延迟 | 1min k线合成到推送的时间 | < 100ms | > 500ms |
| 行情数据断连时长 | 网关断开到重连的时间间隔 | 0s | > 5s |
| 合约覆盖缺口 | 应订阅 vs 实际收到的合约数 | 0 | > 0 |

### 订单执行质量

| 指标 | 说明 | 正常范围 | 告警阈值 |
|------|------|---------|---------|
| 订单往返时间 (RTT) | 从发单到收到交易所确认的时间 | < 100ms | > 500ms |
| 撤单率 | 指定窗口内撤单数量 / 总发单数量 | < 20% | > 40% |
| 成交率 | 指定窗口内成交数量 / 总发单数量 | > 60% | < 40% |
| 部分成交率 | 部分成交订单 / 全部成交订单 | < 10% | > 25% |
| 订单拒绝率 | 被交易所拒绝的订单 / 全部订单 | 0% | > 0% |
| pending 订单数 | 已发出但未成交/未取消的订单数 | < 10 | > 20 |

## 风险层指标

风险层指标用于防范资金回撤超限和仓位失控，详见 [[dashboards]] 中的风险面板配置。

| 指标 | 说明 | 正常范围 | 告警阈值 |
|------|------|---------|---------|
| 当前回撤 (drawdown) | 从历史峰值到当前净值的回撤比例 | < 5% | > 10% |
| 最大回撤 (MDD) | 历史最大回撤幅度 | — | 超过策略预设上限 |
| 资金使用率 | 已占用保证金 / 总资金 | < 60% | > 70% |
| 每日 PnL | 当日累计盈亏（含浮动盈亏） | 正收益 | 当日亏损 > 总资金 × 2% |
| 持仓集中度 | 单一品种持仓市值 / 总资金 | < 15% | > 25% |
| 杠杆倍数 | 总持仓名义价值 / 总资金 | < 3x | > 5x |
| 隔夜敞口 | 收盘后保留的持仓风险暴露 | — | 超过策略预设上限 |
| 品种相关性敞口 | 同方向高相关品种合计敞口 | < 20% | > 30% |

## 策略层指标

策略层指标用于评估每个策略实例的健康状态和收益表现。

| 指标 | 说明 | 采集方式 | 评估频率 |
|------|------|---------|---------|
| 策略信号方向 | 当前持仓方向 (多/空/空仓) | 策略引擎推送 | 实时 |
| 策略信号频率 | 单位时间内信号产生次数 | 按窗口统计 | 1min |
| 策略 PnL | 策略累计盈亏 | 引擎结算 | 实时 |
| 策略夏普比 | 近期滚动夏普比率 | 按日计算 | 1d |
| 策略胜率 | 近期滚动胜率 | 按日计算 | 1d |
| 策略交易次数 | 当日/当周总交易次数 | 按窗口统计 | 1d |
| 策略持仓时长 | 平均每笔持仓时间 | 按窗口统计 | 1d |
| 滑点成本 | 实际成交价与信号发出价之差 | 引擎记录 | 每笔交易 |

## 指标数据存储

所有指标数据统一写入时序数据库，存储策略和保留期如下：

| 数据类型 | 存储引擎 | 原始精度保留 | 聚合保留 |
|---------|---------|-------------|---------|
| 系统指标 | Prometheus / VictoriaMetrics | 7天 (10s) | 30天 (1min)、1年 (1h) |
| 交易指标 | InfluxDB / ClickHouse | 30天 (逐笔) | 1年 (1min) |
| 风险指标 | InfluxDB / ClickHouse | 30天 (快照) | 永久 (1h) |
| 策略指标 | InfluxDB / ClickHouse | 30天 (2s) | 1年 (1min) |
