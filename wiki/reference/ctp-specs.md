## 交易时段

### 日盘

| 交易所 | 时段 |
|--------|------|
| 上期所 (SHFE) | 09:00 - 10:15, 10:30 - 11:30, 13:30 - 15:00 |
| 大商所 (DCE) | 09:00 - 10:15, 10:30 - 11:30, 13:30 - 15:00 |
| 郑商所 (CZCE) | 09:00 - 10:15, 10:30 - 11:30, 13:30 - 15:00 |
| 中金所 (CFFEX) | 09:30 - 11:30, 13:00 - 15:00 |

### 夜盘 (各交易所差异)

| 品种 | 交易时间 |
|------|----------|
| 有色金属（铜、铝等） | 21:00 - 01:00 |
| 黑色系（螺纹钢、铁矿石等） | 21:00 - 23:00 |
| 贵金属（黄金、白银） | 21:00 - 02:30 |
| 能源化工（原油、PTA 等） | 21:00 - 23:00 |
| 股指期货 | 无夜盘 |

### 集合竞价

| 时段 | 时间 |
|------|------|
| 日盘集合竞价 | 08:55 - 09:00 |
| 夜盘集合竞价 | 20:55 - 21:00 |

> 交易时段影响 [[vnpy-docs#CtaTemplate|策略 `on_tick` / `on_bar`]] 推送窗口。

## API 限流

| 限制项 | 阈值 | 说明 |
|--------|------|------|
| 报单频率 | 1 笔 / 500ms | 超限会返回限流错误 |
| 撤单频率 | 1 笔 / 300ms | 建议撤单前加延时 |
| 查询频率 | 1 次 / 2s | 主动查询接口 |
| 单日最大报单 | 依柜台设置 | 超限会被柜台限制交易 |
| 连接超时 | 默认 30s | 可在 `Connect` 参数中设置 |

> 限流导致的问题记录在 [[incidents/template|事故报告]] 中。

## 常见错误码参考

| 错误码 | 含义 | 处理建议 |
|--------|------|----------|
| `1` | 未知错误 | 检查日志，联系柜台 |
| `3` | 报单字段错误 | 检查合约代码、价格格式 |
| `4` | 未登录 | 重新连接登录 |
| `7` | 资金不足 | 追加保证金 |
| `8` | 持仓不足 | 检查可用持仓 |
| `9` | 合约未在交易状态 | 检查当前是否为交易时段 |
| `10` | 报单数量超出限制 | 检查单笔限仓 |
| `24` | 重复报单（报单引用重复） | 检查本地报单引用号 |
| `25` | 报单被拒（风控） | 联系柜台确认风控规则 |
| `26` | 交易所拒单 | 检查参数是否符合交易所规则 |
| `102` | 网关超时 | 检查网络连接 |
| `103` | 连接断开 | 自动重连机制 |
| `104` | 行情连接失败 | 检查 MdAddress |

### 错误处理建议

1. 发现报单失败 → 检查错误码 → 判断是否重试
2. 连接断开 → 自动重连（`CtpGateway` 默认实现）
3. 限流错误 → 增加报单间隔
4. 风控拒绝 → 联系期货公司

## CTP 与 vnpy 关系

```
vnpy (应用层)
  └── CtpGateway (网关层)
        ├── CTP API (C++ → Python Binding)
        │     ├── MdApi   — 行情接口
        │     └── TraderApi — 交易接口
        └── 柜台 (期货公司)
```

| 层 | 职责 | 问题范围 |
|----|------|----------|
| vnpy 策略层 | 策略逻辑、信号生成 | 策略 bug、参数错误 |
| CtpGateway 层 | 协议转换、重连管理 | 配置错误、超时设置 |
| CTP API 层 | 网络通信、业务封装 | 版本兼容、限流、登录认证 |
| 柜台 | 交易所网关、风控 | 账户冻结、风控限制 |
