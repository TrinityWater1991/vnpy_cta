# 策略绩效分析

本文档定义 vnpy CTA 策略的核心绩效指标、跟踪模板及异常处理流程。策略清单请参考 [[catalog]]，各阶段绩效基准见 [[lifecycle]]。

## 核心指标定义

| 指标 | 缩写 | 计算公式 / 定义 | 说明 |
|------|------|----------------|------|
| 年化收益率 | AnnRet | 累计收益率 × (252 / 交易日数) | 年化后的策略收益 |
| 最大回撤 | MaxDD | 峰值到谷值的最大回落幅度 | 衡量策略最大亏损风险 |
| 夏普比率 | Sharpe | (策略收益率 − 无风险利率) / 收益率标准差 | 风险调整后收益 |
| 卡玛比率 | Calmar | 年化收益率 / 最大回撤 | 收益与最大回撤的权衡 |
| 胜率 | WinRate | 盈利交易数 / 总交易数 | 交易胜率百分比 |
| 盈亏比 | ProfitRatio | 平均盈利 / 平均亏损 | 单次盈亏的大小比 |
| 利润因子 | ProfitFactor | 总盈利 / 总亏损 | 总收益与总损失之比 |
| 年化波动率 | AnnVol | 收益率标准差 × √252 | 策略收益波动程度 |
| 单笔最大亏损 | MaxLoss | 单笔交易最大亏损额 | 尾部风险度量 |
